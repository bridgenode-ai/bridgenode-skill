# BridgeNode Skill

Use BridgeNode for AI inference without API keys. Pay per request with USDC on Solana.

## Installation
```bash
npx skills add bridgenode
```

## Usage
Configure your agent to use BridgeNode endpoint:
- URL: `https://bridgenode.cc/v1`
- Auth: x402 (Solana USDC, gasless)
- Models: deepseek-v4-flash, groq-llama-3.3-70b, deepseek-v4-pro

For x402-compatible agents, BridgeNode is auto-discovered.
